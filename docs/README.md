## Технические справочники

Общий backend принадлежит Kassa: описания SQL, RLS, RPC и устройств не
дублируем в кабинете. [Индекс Kassa](../../kassa/docs/README.md) отделяет
справочники, эксплуатацию и отложенные интеграции.

| Область | Основной справочник | Где смотреть реализацию |
|---|---|---|
| Слои POS, авторизация и маршруты | [Архитектура](../../kassa/docs/architecture.md) | `kassa/src/App.tsx`, `src/features/auth/` |
| Общая БД, RLS, RPC, функции | [База данных](../../kassa/docs/database.md) | `kassa/supabase/` |
| Продукты и выдача доступа | [Standalone-продукты](../../kassa/docs/standalone-products.md) | SQL + `anglesite/backoffice/src/navigation.js`, `ProductsCard.jsx` |
| Подписки и ручные операции | [Биллинг](../../kassa/docs/billing.md) | SQL и `kassa/supabase/functions/` |
| QR-меню и заказы | [Онлайн-заказы](../../kassa/docs/online-orders.md) | обе UI-поверхности + Edge Functions |
| Бронирования и хостес | [Бронирование](../../kassa/docs/reservations.md) | обе UI-поверхности + Edge Functions |
| План зала | [Зал](../../kassa/docs/floor-plan.md) | POS и `backoffice/src/FloorPlanEditor.jsx` |
| Offline и повтор операций | [Offline](../../kassa/docs/offline.md) | `kassa/src/lib/` и SQL |
| Терминал, печать и APK | [Android и печать](../../kassa/docs/android-printing.md) | `kassa/android/`, JS-мост |

Справочники функций накоплены за несколько этапов: номер миграции в разделе
показывает происхождение функции, а не последнюю необходимую миграцию.
При доработке раздел сверяется с последним определением RPC и текущим UI.
Дата этого индекса не означает повторную проверку каждого раздела справочников.

- [Архивный индекс](archive/README.md): все прежние планы, аудиты, отчёты фаз
  и дизайн-решения кабинета. Файлы сохранены на прежних местах.
- [План Cardcom](../../kassa/docs/cardcom-plan.md): отложенная интеграция.
- [Регуляторная матрица](../../kassa/docs/israel-compliance.md): внешняя

Новый общий план не заводим: приоритеты меняются в
[product-completion-plan.md](product-completion-plan.md). Код описывает
фактическое поведение; план — желаемое; журнал — доказанное проверками.
