# ANGLE Catalogue — чеклист живой приёмки

Редизайн по `docs/claude-catalogue-approved-redesign-plan.md` (фазы 0–7)
готов ЛОКАЛЬНО. Не закоммичено, не запушено, не задеплоено.

Аудит и матрица правдивости: `docs/catalogue-audit-phase0.md`.

- `npm test` → **434 теста, 82 сюиты, 0 падений** (было 361/61 до правок).
- `npm run build` → успешно, CSS 122.8 kB, JS 824.7 kB.
- Снимки на 1280 / 900 / 430 / 375 / 320 px по всем трём вкладкам —

  валидация правил и диалога категории, круг по вкладкам.

## Что обязан проверить владелец на живых данных

Использовать ТЕСТОВУЮ позицию/категорию/станцию. Ничего не удалять
из продакшена ради проверки внешнего вида.

### Товары

1. Открыть Catalogue. Поиск, `Add category` и `Add item` умещаются в одну
   строку шапки.
2. Найти по настоящему артикулу.
3. Включить `Needs attention` — у каждой строки написано, ЧЕГО не хватает.
4. Открыть позицию: таблица не исчезает и не прыгает, строка подсвечена.
5. Закрыть Escape — фокус вернулся на ту же строку, прокрутка на месте.
6. Изменить описание, фото, артикул, станцию, доступность и размеры —
   группы модификаторов не потерялись.
7. Завести категорию, убедиться, что она появилась в фильтре и в
   редакторе позиции.
8. Выбрать одну позицию, посмотреть предпросмотр `+5%`: сверить «из → во
   что» и точное число ДО применения.
9. У позиции с размерами предпросмотр говорит «N sizes change too».
10. Стрелки порядка мышью и с клавиатуры — в режиме `By category` и в
    списке с одной выбранной категорией.
11. Перезагрузить `?view=menu&tab=stations` — вкладка та же.
12. Перезагрузить с включённым `Needs attention` — отбор сохранился.

### Модификаторы

1. В шапке только `Add modifier group`.
2. Поиск по имени модификатора находит его группу.
3. Открыть группу: правило словами совпадает с min/max.
4. Завести тестовую группу; невозможное min>max не сохраняется.
5. Добавить бесплатный и платный модификатор: `No extra charge` и `+₪N`.
6. Поставить «по умолчанию» и перезагрузить — значение осталось одно.
7. Переставить модификаторы мышью и с клавиатуры — панель не открывается.
8. Escape закрывает панель, фокус возвращается на строку группы.
9. Пустая группа видна через `Needs attention`.
10. Продакшен-группы не удалять.

### Станции

1. В шапке только `Add station`; на экране написано, что это не касса.
2. Сверить счётчики назначенных/непривязанных с реальными `station_id`.
3. `Review items` открывает разбор и позволяет назначить станцию.
4. Открыть станцию: назначенные позиции, их цены, поиск внутри панели.
5. Переименовать ТЕСТОВУЮ станцию, перезагрузить, сверить.
6. Переставить станции мышью и с клавиатуры.
7. Назначить и снять станцию у ТЕСТОВОЙ позиции; после перезагрузки
   счётчик станции и редактор позиции согласны.
8. Диалог удаления говорит, что позиции остаются и теряют станцию
   (это `ON DELETE SET NULL`). Продакшен-станцию не удалять.
9. Ни принтера, ни онлайн/офлайн, ни серийников на экране нет.

### Планшет и телефон

1. 768 / 430 / 375 / 320 px — горизонтальной прокрутки нет.
2. Действия создания достижимы на каждой вкладке.
3. Панели позиции, группы и станции открываются листом на всю высоту.
4. Загрузить тестовое фото — геометрия строки не поехала.
5. Пройти все три вкладки и вернуться — ни белого экрана, ни потери отбора.

## Известные ограничения (не дефекты редизайна)

- **Каналов нет.** В `menu_items` одно `is_available`. Отдельная
  видимость в POS / QR / онлайне — это backend-фаза: модель данных,
  миграция, RPC, права и раскатка на все клиенты.
- **Нет `Duplicate` и `Archive`.** Серверных операций не существует.
- **Каталог общий для организации.** `menu_items` и `modifier_groups` не
  скоупятся по точке; по точке живут только категории и станции. Точка в
  шапке — это выбор владельца новых категорий и станций, а не фильтр
  списка. Полноценная мультиточечность каталога — отдельное продуктовое
  решение.
- **Порядок модификаторов пишется построчно.** Атомарного RPC для них
  нет (`reorder_menu` знает категории, товары и станции). При обрыве
  связи часть порядка может примениться — данные не портятся, порядок
  поправим повторным нажатием.
- **Право на запись проверяет сервер.** Клиент не угадывает роль:
  отказ показывается человеческим текстом там, где действие начали.
- **Страниц нет.** Каталог грузится целиком; «48 items / 1 2 3» из
  макета появится вместе с серверной пагинацией, когда она понадобится.
